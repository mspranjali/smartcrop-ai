# SmartCrop AI – Crop Recommendation System

A beginner-friendly machine learning web application that recommends crops based on
soil and climate parameters. Built with Python, Flask, scikit-learn, and vanilla HTML/CSS/JS.

---

## Features

- Compares **Decision Tree**, **KNN**, and **Random Forest** classifiers
- Selects and saves the best model automatically
- Real-time predictions via a Flask web interface
- Model performance page with accuracy, F1-score, confusion matrix, and per-class stats
- Responsive, agricultural-themed design
- Aligned with **SDG 2** (Zero Hunger) and **SDG 12** (Responsible Consumption)

## Installation

### 1. Clone / download the project

```bash
git clone <repository-url>
cd "SmartCrop AI"
```

### 2. Create and activate a virtual environment (recommended)

```bash
# Windows
python -m venv venv
venv\Scripts\activate

# macOS / Linux
python3 -m venv venv
source venv/bin/activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

---

## Running the Application

### Step 1 – Train the model (run once)

```bash
python train_model.py
```

This will:
- Load and validate the dataset from `dataset/Crop_recommendation.csv`
- Train and compare Decision Tree, KNN, and Random Forest models
- Save the best model to `models/best_model.pkl`
- Save evaluation metrics to `models/metrics.json`

Expected output:
```
Loading dataset …
  Rows: 2200  |  Classes: 22  |  Nulls: 0
  Train: 1760  |  Test: 440
  Decision Tree    acc=0.xxxx  f1=0.xxxx
  KNN              acc=0.xxxx  f1=0.xxxx
  Random Forest    acc=0.xxxx  f1=0.xxxx

Best model: Random Forest (F1=0.xxxx)
Model saved  → models/best_model.pkl
Metrics saved → models/metrics.json

Training complete. Run  python app.py  to start the web application.
```

### Step 2 – Start the web application

```bash
python app.py
```

Open your browser and navigate to: **http://127.0.0.1:5000**

## Usage

| Page | URL | Description |
|------|-----|-------------|
| Home | `/` | Introduction and project overview |
| Recommend | `/recommend` | Enter soil/climate values to get a crop suggestion |
| Performance | `/performance` | View real model metrics and comparison chart |
| About | `/about` | Methodology, SDGs, and limitations |

### Input ranges accepted

| Parameter | Range | Unit |
|-----------|-------|------|
| Nitrogen (N) | 0 – 200 | kg/ha |
| Phosphorus (P) | 0 – 200 | kg/ha |
| Potassium (K) | 0 – 200 | kg/ha |
| Temperature | -10 – 55 | °C |
| Humidity | 0 – 100 | % |
| Soil pH | 0 – 14 | — |
| Rainfall | 0 – 4000 | mm |

## Disclaimer

Recommendations are generated by a machine learning model trained on historical
agricultural data. They do not account for local pest pressure, market conditions,
soil microbiome, or other agronomic factors, and **do not guarantee crop success**.
Always consult a qualified agronomist before making planting decisions.
